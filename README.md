# TalentBridge

## Overview

TalentBridge is a Placement Management System developed using Spring Boot and MongoDB. It helps manage Students, Companies, Jobs, and Applications through REST APIs.

## Technologies Used

* Java 17
* Spring Boot
* Spring Data MongoDB
* MongoDB
* Spring Security
* JWT Authentication
* Swagger/OpenAPI
* Maven

## Features

### Student Management

* Create Student
* View Students
* Update Student
* Delete Student

### Company Management

* Create Company
* View Companies
* Update Company
* Delete Company

### Job Management

* Create Job
* View Jobs
* Update Job
* Delete Job

### Application Management

* Apply for Jobs
* View Applications
* Update Application Status
* Delete Applications

### Dashboard Analytics

* Total Students
* Total Companies
* Total Jobs
* Total Applications

### Authentication

* User Registration
* User Login
* JWT Token Generation

## API Testing

All APIs were tested using Postman and documented using Swagger UI.

## Run Project

Clone the repository and run:

mvn spring-boot:run

## Swagger URL

http://localhost:8080/swagger-ui/index.html
